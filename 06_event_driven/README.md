## 📄 `Makefile`

```makefile
.PHONY: build clean

build:
	docker compose build --no-cache medical-api

clean:
	docker compose down -v --remove-orphans
```
*(Важно: отступы перед командами `docker` должны быть выполнены символом табуляции, а не пробелами)*

## Описание проекта
Реализация событийно-ориентированной архитектуры для системы управления медицинскими записями. Проект демонстрирует работу с брокером сообщений Apache Kafka, применение паттерна CQRS и реализацию компонентов producer/consumer на C++ с использованием библиотеки POCO и librdkafka.

Документация:
- [event_driven_design.md](event_driven_design.md) — архитектурное описание, проектирование CQRS, выбор брокера и гарантии доставки
- [event_catalog.md](event_catalog.md) — каталог событий с описанием payload, производителей и потребителей

## Требования
- Docker и Docker Compose
- Утилита make
- Свободные порты: 8080, 8081, 9092, 29092, 2181, 5432

## Запуск проекта
Для управления окружением предусмотрены цели в Makefile:

1. Сборка образа приложения:
```bash
make build
```

2. Запуск всех сервисов:
```bash
docker compose up -d
```

3. Остановка и полная очистка контейнеров и томов:
```bash
make clean
```
